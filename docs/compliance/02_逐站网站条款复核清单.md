# 逐站网站条款复核清单（技术性 Checklist）

> **性质声明**：本文件为 AI 辅助整理的**逐站复核清单（技术性过程文档）**，不构成法律意见。robots.txt 与使用条款的合规判断、以及是否实际抓取/转载，最终由责任人（发布者）逐站人工复核并承担相应责任。本清单列明各源的已知信息、待办项与责任人动作，**标注"需人工"的项必须由责任人亲自访问站点确认并截图存档**。

---

## 核验口径说明

- **robots.txt**：网站对自动化爬虫的访问限制声明，非法律强制，但违反可能引发合同/侵权风险。本工具 `--try-online` 仅对用户提供的确切官方 URL 做**单次、人工触发** GET，一般不视为突破 robots；但仍须结合各站"使用条款"判断。
- **使用条款 / 版权声明**：可能含"禁止转载""禁止商业使用"等超出 robots.txt 的限制，须逐站人工复核。政府网站通常允许公众使用主动公开信息，但个别站点可能有特殊声明。
