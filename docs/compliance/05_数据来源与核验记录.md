## 说明

- 单行 SHA 可用 `shasum -a 256 <文件>` 生成；建议按"每部法一个导出文件"分别计哈希，便于追溯。
- **北京 canonical PDF**（`bjrd.gov.cn`）SHA 待 **O2** 补录。

- 本表仅含 law-cli 现有三部法；若后续扩展（如纳入 verified-chinese-law-kb 的著作权法 / 北京 / 上海，见开放项 O4），须另起行并附律师核验。
