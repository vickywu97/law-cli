# law-cli · 法条速查器（数据合规 MVP）

> **✅ 真实态声明（非虚构示例）**
> 本仓库现为**真实可复现数据项目**：法条原文取自官方公开渠道（依《著作权法》第五条属公共领域），每条固定完整证据链（来源URL / 公布·施行日期 / 检索日期 / SHA-256），可离线复现。各法规"核验状态"见《地方性法规官方源调研.md》§2.1 / §2.2。
> 用户（律师/税务师/专利代理师）专业资质不为本工具输出增信；官方版本认定与效力提示以官方发布为准。

> **⚠️ A 类 · 法律免责**
> 本工具仅整理公开法条原文，效力状态提示以官方发布为准，**不构成法律意见**，使用者须自行核实。具体事项请咨询具备相应资质的执业律师。

---

## 这是什么

law-cli 是"法条速查器"的**数据层最小闭环**：先解决最敏感的 IP 环节——法条原文的合法获取、固定来源、可复现证明——再谈查询与效力标注。

当前已实现命令：
- `law fetch`：记录官方原文 + 完整证据链（来源URL / 公布·施行日期 / 检索日期 / SHA-256）。
- `law show`：显示条文 + 来源 + 哈希 + 免责横幅。
- `law verify`：校验本地数据是否被篡改（防篡改）。
- `law versions <法名.条号>`：版本轴，多版本原文并排 + 差异对比（difflib，仅文本比对）。
- `law validity [法律名]`：效力红黄绿（依各版本 effective_date 与当前日期自行判断）。
- `law check <法律名第X条>`：最小引用校验，返回最新有效版本原文与状态。
- `law check-batch <文件>`：批量校验文本文件中的引用（每行一条 `法律名第X条`），输出逐行结果 + 汇总（匹配/未匹配/解析失败）。仅基于本地库，不访问外部。
- `law relate <法名.条号> [--kb-path]`：查询本地 `verified-chinese-law-kb`（默认 `../verified-chinese-law-kb`）中的关联线索；KB 不存在时明确提示且不自动抓取第三方库。

> ⚠️ **来源合规警示（实测）**：从第三方商业库（如威科先行 wkinfo）导出的 `.doc`/`.pdf` 虽含法条原文（公共领域），但内嵌其专属超链接、`时效性`标注等增值内容，属红线4禁止复制范围。本工具一律以**官方数据库（flk.npc.gov.cn）**为 `source-url`，绝不采用商业库导出件作为来源。

示例数据：以《著作权法》第1–5条演示，含 **2010 修正**与 **2020 修正**两个官方原文版本（均公共领域，人工保存自官方渠道导入），共 10 条记录。另附 `地方性法规官方源调研.md`（已完成北京、上海两省试点与官方源核验）。

## 为什么这样切

- 直接验证最不确定的链路：官方版本能否稳定获取、证据链能否固定。
- 不碰任何第三方增值内容，风险最低。
- 跑通后可自然扩展版本轴、效力红黄绿、Bench 引用校验。

## 合规红线（贯穿始终）

1. **来源唯一化**：全国性法律只从官方公开渠道（国家法律法规数据库 flk.npc.gov.cn / 中国人大网 / 国务院公报）获取。
2. **只提取条文原文**：不下载、不存储任何汇编结构、分类、注释、效力说明。
3. **完整证据链**：来源URL + 公布日期 + 施行日期 + 检索日期 + SHA-256。
4. **不碰第三方增值内容**：北大法宝、威科先行、无讼等一律不碰。
5. **不附法律意见**：所有输出带免责横幅。
6. **遵守 robots / 使用条款**：自动化抓取被禁时，改用"人工保存官方原文 + 记录"（即本 MVP 的 `fetch --file` 路径）；`--try-online` 仅对用户提供的确切官方URL做单次GET并落盘供人工核对，绝不自动解析第三方结构。

## 法条原文的版权边界（《著作权法》第五条）

- 法律、法规及国家机关具立法/行政/司法性质的文件及其官方正式译文，**不适用著作权法** → 法条原文属公共领域，可合法复制，但须用**官方版本**并**注明来源**。
- 官方公报/数据库若仅按时间顺序机械汇编，独创性不足，不受保护；但其**分类目录、导航、专题汇编、条文注释、效力标注、案例关联**等受版权保护，**禁止复制**。
- 结论：只取条文文本，剥离编排/注释/说明。

## 快速开始（零依赖，仅标准库）

```bash
# 0) 准备：从国家法律法规数据库人工保存某法官方原文为 UTF-8 文本
# 1) 记录（fetch）—— 手动导入官方原文，工具补全证据链
python3 law_cli.py fetch \
  --law "中华人民共和国著作权法" \
  --file "seed/著作权法_总则_第1-5条_官方原文.txt" \
  --source-url "https://flk.npc.gov.cn/search.html?keyword=著作权法" \
  --publisher "全国人民代表大会常务委员会" \
  --published-date 2020-11-11 --effective-date 2021-06-01 \
  --version-tag "2020修正（第三次修正，主席令第六十二号）" \
  --articles 1-5

# 2) 查看（show）
python3 law_cli.py show "著作权法.5"      # 单条
python3 law_cli.py show                    # 列出全部

# 3) 校验（verify）—— 防篡改
python3 law_cli.py verify

# 4) 版本轴（versions）—— 需先导入同一法条的多个版本
python3 law_cli.py fetch --law "中华人民共和国著作权法" \
  --file "seed/著作权法_2010修正_第1-5条_官方原文.txt" \
  --source-url "https://www.nppa.gov.cn/.../t20160429_4556.html" \
  --publisher "全国人民代表大会常务委员会" --published-date 2010-02-26 \
  --effective-date 2010-04-01 --version-tag "2010修正（第二次修正，主席令第二十六号）" \
  --articles 1-5
python3 law_cli.py versions 著作权法.3      # 两版原文 + 差异

# 5) 效力红黄绿（validity）
python3 law_cli.py validity 中华人民共和国著作权法

# 6) 引用校验（check）
python3 law_cli.py check "著作权法第5条"

# 7) 批量校验（check-batch）—— 文件每行一条引用
python3 law_cli.py check-batch test_citations.txt
#   输出逐行 ✓/✗ + 末尾汇总：引用 N | 匹配 M | 未匹配 K | 解析失败 L

# 8) 关联查询（relate）—— 对接本地 verified-chinese-law-kb
#   默认 --kb-path ../verified-chinese-law-kb（仓库通常不在本目录）；用 --kb-path 指向实际位置
KB=/path/to/verified-chinese-law-kb
python3 law_cli.py relate 公司法.1 --kb-path "$KB"
python3 law_cli.py relate 民法典.1032 --kb-path "$KB"
#   若 KB 不存在：打印合规提示，不抓取第三方库
#   若 KB 存在：按 law_code + 条号精确匹配，返回已核验原文摘要 + 来源(flk.npc.gov.cn) + verified 标记 + 免责横幅
#   注意：该 KB 当前收录 民法典/刑法/公司法/专利法/税收征管法/增值税法/企业所得税法/个人所得税法，
#         不含《著作权法》——relate 著作权法.x 会如实报"未找到"，不会伪造线索。
#   合规复查：本仓库为自建、MIT 许可、每条经执业律师核验并具名签署；source_url 全为
#             flk.npc.gov.cn / gov.cn 官方域，零商业库痕迹（仅 law-citation-bench/preds 的
#             模型预测文本里出现"北大法宝/法信"等字样，属评测样本，非 KB 数据来源）。

# 9) 地方性法规试点（多源扩展）—— 同一套 fetch 流程，来源锁定省级官方站
python3 law_cli.py fetch \
  --law "北京市生活垃圾管理条例" \
  --file "seed/北京市生活垃圾管理条例_2020修正_全文_官方原文.txt" \
  --source-url "https://www.beijing.gov.cn/zhengce/dfxfg/202009/t20200929_2102701.html" \
  --publisher "北京市人民代表大会常务委员会" \
  --published-date 2020-09-25 --effective-date 2020-09-25 \
  --version-tag "2020修正（第十五届人大常委会第二十四次会议修改，公告第39号）"
#   要点：来源锁定省级官方站（beijing.gov.cn·主动公开；canonical=bjrd.gov.cn 人大公报PDF，
#         其 SHA-256 已记录为 provenance 标记）；法规原文依《著作权法》第五条属公共领域，
#         可合法使用；全程不碰任何商业库。robots 核查：beijing.gov.cn 仅 Disallow /sd。
#   试点结果：导入 79 条，DB 现共 89 条，verify 89/89 完好；详见 地方性法规官方源调研.md。
```
